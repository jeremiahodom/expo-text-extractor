🔍 Overview

Expo Text Extractor is a modern React Native library that brings powerful Optical Character Recognition (OCR) capabilities to your mobile applications. Built specifically for Expo projects, it leverages native platform technologies to deliver accurate and efficient text extraction from images.

Key Features

  • Cross-Platform Support: Works seamlessly on Android and iOS devices
  • Native Performance: Uses Google ML Kit on Android and Apple Vision on iOS
  • Easy Integration: Simple API with just two main functions
  • Modern Architecture: Built for Expo SDK 52+ with TypeScript support
  • Real-time Processing: Efficient text recognition from camera or gallery images
💡 Pro Tip: This library is perfect for applications that need to extract text from receipts, documents, business cards, signs, or any image containing text.

📦 Installation

Getting started with Expo Text Extractor is simple. Follow these steps to add it to your project:

Prerequisites

⚠️ Important: Ensure your project is running Expo SDK 52 or higher.

Install the Package

Use the Expo CLI to install the library:

npx expo install expo-text-extractor

Alternative Installation

You can also use npm or yarn:

npm install expo-text-extractor
yarn add expo-text-extractor

Configuration

No additional configuration is required! The library works out of the box with Expo managed workflow.

📚 API Reference

The Expo Text Extractor provides a simple and intuitive API with two main exports:

isSupported

Type: boolean

A boolean value that indicates whether the text extraction module is supported on the current device.

Usage Example:

import { isSupported } from 'expo-text-extractor'; if (isSupported) { console.log('Text extraction is supported on this device.'); } else { console.log('Text extraction is not supported on this device.'); }

extractTextFromImage(uri: string)

Type: Promise<string[]>

Extracts text from an image and returns the recognized text as an array of strings.

Parameters:

uri (string): The URI of the image to extract text from. Supports both local file URIs and remote URLs.

Returns:

A Promise that resolves to an array of strings, where each string represents a line of recognized text.

Usage Example:

import { extractTextFromImage } from 'expo-text-extractor'; const extractText = async (imageUri: string) => { try { const extractedTexts = await extractTextFromImage(imageUri); console.log('Extracted texts:', extractedTexts); return extractedTexts; } catch (error) { console.error('Text extraction failed:', error); return []; } };

💡 Examples

Basic Usage with Image Picker

import React, { useState } from 'react'; import { View, Button, Text, Alert } from 'react-native'; import { launchImageLibraryAsync } from 'expo-image-picker'; import { extractTextFromImage, isSupported } from 'expo-text-extractor'; export default function App() { const [extractedText, setExtractedText] = useState<string[]>([]); const handleImagePicker = async () => { if (!isSupported) { Alert.alert('Error', 'Text extraction is not supported on this device'); return; } const result = await launchImageLibraryAsync({ mediaTypes: ['images'], }); if (!result.canceled && result.assets?.[0]) { try { const texts = await extractTextFromImage(result.assets[0].uri); setExtractedText(texts); } catch (error) { Alert.alert('Error', 'Failed to extract text from image'); } } }; return ( <View style={{ flex: 1, padding: 20 }}> <Button title="Pick Image & Extract Text" onPress={handleImagePicker} /> {extractedText.length > 0 && ( <View style={{ marginTop: 20 }}> <Text style={{ fontWeight: 'bold' }}>Extracted Text:</Text> {extractedText.map((line, index) => ( <Text key={index} style={{ marginTop: 5 }}>{line}</Text> ))} </View> )} </View> ); }

Camera Integration Example

import { launchCameraAsync } from 'expo-image-picker'; import { extractTextFromImage } from 'expo-text-extractor'; const handleCameraCapture = async () => { const result = await launchCameraAsync({ mediaTypes: ['images'], }); if (!result.canceled && result.assets?.[0]) { const extractedTexts = await extractTextFromImage(result.assets[0].uri); console.log('Camera extracted text:', extractedTexts); } };

Error Handling Best Practices

const safeTextExtraction = async (imageUri: string): Promise<string[]> => { try { // Check device support first if (!isSupported) { throw new Error('Text extraction not supported on this device'); } // Validate URI if (!imageUri || typeof imageUri !== 'string') { throw new Error('Invalid image URI provided'); } const result = await extractTextFromImage(imageUri); // Handle empty results if (!result || result.length === 0) { console.log('No text found in the image'); return []; } return result; } catch (error) { console.error('Text extraction error:', error); // Return empty array instead of throwing in production apps return []; } };
